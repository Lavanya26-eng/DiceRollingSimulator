# 🎲 Dice Rolling Simulator

A simple Python program that simulates rolling a six-sided dice. Each time the program runs, it generates a random number between **1 and 6**.

## Features

- Generates a random dice value (1–6)
- Uses Python's built-in `random` module
- Simple and beginner-friendly
- Runs in the command line/terminal

## Technologies Used

- Python 3
- Random Module

## Project Structure

```
DiceRollingSimulator/
│── dice_rolling_simulator.py
└── README.md
```

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:

```bash
python dice_rolling_simulator.py
```

## Sample Output

```
🎲 Rolling the dice...
You rolled: 5
```
